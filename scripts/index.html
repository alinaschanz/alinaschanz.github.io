the scripts

seven repositories: six in python 3.10+ with the standard library only, one typescript twin with zero dependencies, all on public endpoints, no keys. status below is read live from github.

i keep them public so that a number in a post can be rerun instead of believed. every commit is signed. the tests run on every push on python 3.10, 3.12 and 3.13.

onchain-notes

the numbers i look at before posting anything: prices, base fee, fear & greed, tvl by chain, btc dominance. one card, one screen. plus what a transfer, a swap and a mint cost right now, in cents.

…
python daily_card.py

gasweek

when is ethereum cheapest? the base fee of every block of the last week, binned by hour of day and weekday, as a table and an svg. writes the daily dataset.

…
pip install git+https://github.com/alinaschanz/gasweek && gasweek --tz +2

bigmoves

large stablecoin, weth and wbtc transfers in the last n blocks, priced, with exchange and bridge labels. --follow keeps watching.

…
bigmoves --blocks 50 --min-usd 1000000

stablepeg

are the stablecoins still a dollar? uniswap v3 spot and a ten-minute twap from the deepest pool, a curve 3pool quote for 100k, coingecko next to it.

…
stablepeg

ens-lookup

ens names to addresses and back, text records included. pure python, its own keccak-256, reverse lookups confirmed forward.

…
enslookup vitalik.eth --all-text

gasweek-js

gasweek for the browser and node: the same pages of eth_feeHistory, the same interpolation and percentiles, in typescript with zero dependencies. import { gasweek, table } from "gasweek".

…
npm install github:alinaschanz/gasweek-js
