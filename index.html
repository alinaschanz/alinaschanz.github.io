everything is python 3.10+, standard library only, public json-rpc endpoints, no api keys. if a number in a post looks off, the script that produced it is here.

  • onchain-notesthe numbers i look at before posting anything: prices, base fee, fear & greed, tvl. one card, one screen.
  • gasweekwhen is ethereum cheapest? base fee by hour of day over the last week, as a table and an svg.
  • bigmoveslarge stablecoin, weth and wbtc transfers in the last n blocks, with exchange and bridge labels.
  • stablepegare the stablecoins still a dollar? uniswap v3 spot and twap, a curve 3pool quote, coingecko next to it.
  • ens-lookupens names to addresses and back, text records included. pure python, keccak and all.
  • alinaschanz.github.iothis page. hand-written html and css, no framework, no trackers, no cookies.
