where the numbers come from

every figure on this site or in a post, with the endpoint and the formula behind it.

a number without a method is an opinion with digits. this page is the method. it is boring on purpose.

the rules

  • public endpoints only. no api keys, no private feeds, no data i cannot show you how to fetch.
  • python 3.10 or newer, standard library only. nothing to install, nothing that can quietly change under me.
  • every script prints the block number or timestamp it read, so a number can be pinned to a moment.
  • when a source is rate limited, the script falls back to another public source and says so. it never fills a gap with a guess.

gasweek: when is ethereum cheapest

eth_feeHistory is paged 1,024 blocks at a time until a week is covered, 50,400 blocks. base fees are exact per block. block timestamps are only fetched for the first and last block of each page and interpolated in between, so the hour a block lands in is right to within a few seconds, never to the second. the base fees are then binned by hour of day and by weekday and summarised as min, p25, median, p75, p90 and max. the daily dataset is one such row per day, written at 00:17 utc by a github workflow, with the block range it covered.

bigmoves: large transfers

eth_getLogs for the erc-20 Transfer topic over windows of 25 blocks, for usdt, usdc, dai, weth, wbtc and a few more. symbol and decimals are read from each contract, not assumed. weth and wbtc are priced with coingecko, the stablecoins at one dollar. addresses are named from a public label set (the 2023 etherscan labels dataset) plus a short list i maintain by hand: exchange hot and cold wallets, bridges, routers, a lending pool. a label is a hint about who an address is, never proof.

stablepeg: are the stablecoins still a dollar

for each coin the uniswap v3 factory is asked for the pool against usdc at every fee tier, the pool with the most liquidity wins, its slot0 gives the spot price and observe() a ten-minute time-weighted average. ten minutes is short on purpose: the question is "now", not "this month". curve 3pool answers what 100,000 usdt or dai returns in usdc through get_dy. coingecko sits in the last column as a sanity check. anything fifty basis points or more off gets a flag; frax and lusd wear it most weeks and that is not news.

ens-lookup: names and addresses

namehash needs keccak-256, and python ships nist sha3 which pads differently, so the package carries its own keccak, checked against hashlib and the published test vectors. lookups go registry → resolver → addr or text. reverse lookups are confirmed with a forward lookup before they are shown, because a reverse record alone can say anything.

what can go wrong

  • public nodes lag a block or two and sometimes disagree with each other for a moment. the block number is printed so you can tell.
  • a base fee is what the chain charges, not what you pay. the tip is on top, and wallets overestimate it.
  • percentiles over a week hide the spikes. the max column exists for that reason.
  • labels age. an exchange rotates a wallet and the label stays on the old one.
  • coingecko limits requests per ip, so the front page may show the fallback source. the caption says which.

git clone https://github.com/alinaschanz/onchain-notes
cd onchain-notes
python daily_card.py

if the card does not match a post of mine from the same hour, write to hello@alinaschanz.life. mistakes go on the corrections list, the post stays up.
