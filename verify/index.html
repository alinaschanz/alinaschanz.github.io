is this really me?

the handful of places i exist, how they point at each other, and how to check a signature.

accounts get copied. the easiest way to know you are talking to me is that everything below points at everything else, and nothing outside this list is me.

the key

get it from /pgp.txt, or let gpg find it through this domain (web key directory):

gpg --locate-keys hello@alinaschanz.life

the fingerprint gpg prints has to match the one above. if it does not, stop.

check a commit

git clone https://github.com/alinaschanz/gasweek
cd gasweek
gpg --import <(curl -s https://alinaschanz.life/pgp.txt)
git log --show-signature -1

"good signature from alina schanz" with the fingerprint above means the code is what i pushed. github shows the same check as a "verified" badge on each commit.

check a number

every number in a note or a post comes from a script in one of the repositories. the methods page says which endpoint and which formula. if a rerun gives you something else, the note is wrong and i want to know.

check a note

every note on this site has an opentimestamps proof next to it: the same file name with .ots at the end. it proves the note existed, byte for byte, before a certain bitcoin block, without anybody having to trust me or this server. a note that changes gets a new proof, and the change goes in the changelog.

curl -sO https://alinaschanz.life/notes/2026-09-08-week-37-in-numbers.html
curl -sO https://alinaschanz.life/notes/2026-09-08-week-37-in-numbers.html.ots
ots verify 2026-09-08-week-37-in-numbers.html.ots

ots is pip install opentimestamps-client; checking the block needs a bitcoin node, or drop both files on opentimestamps.org and let the page do it. a fresh proof reads "pending" for a few hours until a block covers it; after that it is final.

let somebody else check

the key above carries two machine-readable proofs in the ariadne format: a gist on my github account and a txt record on this domain, each naming the key's fingerprint. keyoxide fetches the key through this domain and checks both in your browser, with nothing of mine in the loop. the key is also on keys.openpgp.org.

what this page cannot prove

the accounts above point at each other, the commits are signed, the notes are timestamped. that proves three things and no more: what lands on github comes from whoever holds the key, a note existed byte for byte before a certain bitcoin block, and a number in a note comes out of a script you can rerun. it does not prove who holds the key. the key was made in september 2026 and everything on this page is about as old as the key; the x account is older, and its age is a date, not a credential, so do not let it stand in for anything. what you can check is the numbers, the scripts and the signatures. check those, and give the rest exactly as much trust as a few weeks of public work has earned.
