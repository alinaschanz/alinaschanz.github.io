changelog

what changed on this site, when. newest first. the full history is in the repository.
  • 8 sep 2026
    the timeline, told straight.

    the front page said "on x since 2015" as if that meant something; it does not, so it is gone. the about page now says what the account was before this: a personal feed in german, about a year of it, then nothing for ten years. the verify page says the same, and that the site, the github account and the key are all from this week. the age of an account is not a credential; a rerun of the scripts is. the old line is the first entry under corrections. the verify page also got a section on what it cannot prove: who holds the key, and whether that is the person who wrote here in 2016.

  • 8 sep 2026
    proofs, part two.

    the key carries two ariadne proofs, a gist on github and a dns record on this domain, that keyoxide checks in your browser; see the verify page. the key is on keys.openpgp.org as well.

  • 8 sep 2026
    proofs.

    every note now has an opentimestamps proof next to it, the .ots file. an indexnow key, so search engines hear about a change the moment it is published, and the main pages are handed to the wayback machine after every publish.

  • 8 sep 2026
    the first weekly note.

    week 37 in numbers: the base fee by hour of day, nine stablecoin pegs and one hour of large transfers, every number from the scripts on github with the command next to it. a chart image under /img/notes/. one of these every week from now on.

  • 8 sep 2026
    live numbers that survive a bad network.

    every tile on the home page now has a second and a third source (coinbase and kraken for the prices and the chart, a fourth public node for the base fee), a failed request is tried once more, and when a tile still gives up the page says why that usually happens and offers a "try again" link instead of a silent dash. cryptocompare dropped: it wants an api key now. the privacy table and methods list the new hosts.

  • 8 sep 2026
    trust round.

    fonts served from here instead of a font network. a content security policy on every page, listing the only hosts a page may call. new pages: verify (accounts, pgp key, how to check a commit), methods, data with the daily base fee dataset read live, scripts with live status, privacy with a switch for the live numbers, now, this changelog. a signed security.txt, the key at /pgp.txt and through web key directory, a json feed next to the atom one, a web manifest, structured data on every page, a skip link for keyboards.

  • 8 sep 2026
    v3.

    berlin time and weather next to the live numbers, coordinates under the portrait, the latest note as a card with a quote, the six repositories as cards, a three-column footer, humans.txt.

  • 8 sep 2026
    v2.

    the about page with the disclosure: no paid posts, no calls, no trading around my own notes, sources named, corrections stay visible. the bitcoin 7-day chart with two fallback sources.

  • 8 sep 2026
    first version.

    home with live numbers, the first note, an atom feed, a sitemap, a 404 page with a reorg joke.
